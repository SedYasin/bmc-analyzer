# بوم کسب‌وکار پیام

ابزار فرایندمحور برای تحلیل استارتاپ‌ها و کسب‌وکارها بر پایهٔ بوم کسب‌وکار (Business Model Canvas)، نسخهٔ ارتقایافتهٔ تمپلیت اکسلی «بوم کسب و کار» (طراحی: سید یاسین پیام).

## چه کار می‌کند

کار در ۵ مرحله پیش می‌رود:

1. **دریافت اطلاعات:** مشخصات پرونده، مرحلهٔ استارتاپ، یادداشت‌های خام بنیان‌گذار و پیام آمادهٔ درخواست اطلاعات پیش از جلسه.
2. **تکمیل بوم:** ۹ بلوک اصلی و ۲ بلوک مکمل (رقابت و مزیت، تیم و اجرا).
   - سؤال‌های غنی‌شده در دو حالت «کلیدی» و «کامل»
   - سؤال مخصوص هر مرحله (ایده / MVP / کشش بازار / رشد)
   - گزینه‌های انتخابی به جای تایپ
   - علامت ابهام همراه با سؤال دقیق برای بنیان‌گذار
   - نمرهٔ ۱ تا ۵ با معیار مشخص، و سطح شواهد
3. **اقتصاد واحد:** محاسبهٔ LTV، نسبت LTV به CAC، زمان برگشت هزینهٔ جذب، نقطهٔ سربه‌سر و مدت دوام نقدینگی (runway).
4. **پیگیری ابهام‌ها:** همهٔ موارد مبهم در یک پیام آماده برای بنیان‌گذار جمع می‌شوند.
5. **داشبورد و تحلیل:**
   - نمرهٔ سلامت مدل از ۱۰۰، و مقایسهٔ نمره‌ها با انتظار مرحله
   - هشدارهای خودکار ناسازگاری
   - تحلیل هوش مصنوعی
   - خروجی اکسل، گزارش قابل‌چاپ و فایل پرونده (`.json`)

## روش‌های استفاده

| روش | هوش مصنوعی | دانلود فایل |
|---|---|---|
| Artifact در Claude | خودکار، داخل برنامه | از طریق Claude |
| باز کردن `index.html` روی کامپیوتر | روش دستی: کپی پرامپت ← پاسخ Claude را بچسبانید | مستقیم با مرورگر |
| GitHub Pages | روش دستی | مستقیم با مرورگر |

**اجرای لوکال:** فایل `index.html` را دانلود کنید و با دوبار کلیک در Chrome یا Edge باز کنید. نیازی به نصب چیزی نیست.

**نکته‌ها:**
- همهٔ اطلاعات فقط در مرورگر خودتان می‌ماند و جایی ارسال نمی‌شود.
- پیش‌نویس در حافظهٔ همان مرورگر نگه داشته می‌شود. برای جابه‌جا کردن کار بین سیستم‌ها از «ذخیرهٔ پرونده» و «باز کردن پرونده» استفاده کنید.
- فونت‌ها (Vazirmatn) و کتابخانهٔ خروجی اکسل (SheetJS) از اینترنت بارگذاری می‌شوند. بدون اینترنت، برنامه با فونت پیش‌فرض کار می‌کند ولی خروجی اکسل در دسترس نیست.

## ساختار پروژه

```
src/page.html   ساختار صفحه و استایل‌ها
src/data.js     بانک سؤالات، گزینه‌ها، معیار نمره‌دهی و وزن بلوک‌ها
src/app.js      منطق برنامه: محاسبات، قواعد هشدار، هوش مصنوعی، خروجی‌ها
build.py        سرهم کردن فایل‌ها
index.html      نسخهٔ مستقل (ساخته‌شده؛ مستقیم ویرایش نکنید)
artifact.html   نسخهٔ قابل‌انتشار در Claude (ساخته‌شده)
```

## تغییر سؤال‌ها یا قواعد

- **سؤال‌ها، گزینه‌ها و معیارهای نمره:** در `src/data.js`، آرایهٔ `BLOCKS`. هر سؤال به شکل `[شناسه، متن، راهنما، کلیدی؟]` است.
- **وزن بلوک‌ها در نمرهٔ سلامت:** فیلد `weight` هر بلوک.
- **انتظار نمره در هر مرحله:** فیلد `exp` در آرایهٔ `STAGES`.
- **قواعد هشدار و ناسازگاری:** تابع `warnings()` در `src/app.js`.

بعد از هر تغییر این دستور را اجرا کنید:

```bash
python3 build.py
```
